# acess-drivers
Acess Drivers: Tecnologia a serviço da inclusão. Porque o transporte deve ser para todos, sem exceções ou desculpas
♿ Acess Drivers - Mobilidade Sem Barreiras
"A tecnologia só é avançada quando é inclusiva."
O Acess Drivers nasce de uma dor real e frequente no cenário da mobilidade urbana por aplicativos. O projeto é um protótipo de interface focado exclusivamente no atendimento a Pessoas com Deficiência (PCD) e pessoas com mobilidade reduzida.
💡 A Motivação
A ideia para este projeto surgiu de uma experiência pessoal frustrante com a minha mãe. Quantas vezes pedimos um carro por aplicativo e, ao chegar, o motorista cancela a viagem ao ver a cadeira de rodas, alegando falta de espaço no porta-malas (devido ao cilindro de gás) ou simplesmente recusando o atendimento com frases como: "Você deveria ter avisado antes".
Essas situações geram desmotivação, exclusão e forçam famílias a buscarem transportes particulares caros por medo do descaso nos apps convencionais. O Acess Drivers propõe um fluxo onde a necessidade do passageiro é a prioridade número um, garantindo que o motorista que aceitar a corrida já esteja preparado e equipado para atender com dignidade.
🛠️ Funcionalidades Técnicas
O projeto foi desenvolvido focando em três pilares principais:
Tagging & DataLayer (Analytics): Implementação de uma estrutura de dados profissional para monitorar o comportamento do usuário e garantir que o fluxo de solicitação seja o mais rápido e eficiente possível.
Acessibilidade Nativa (A11y): Uso de atributos ARIA, alto contraste e feedback sonoro via SpeechSynthesis API para usuários com deficiência visual.
Filtragem de Requisitos: O sistema identifica automaticamente se a categoria do perfil selecionado (ex: Cadeira Motorizada) exige hardware específico (rampa/elevador) antes de enviar a tag de solicitação.
🚀 Tecnologias Utilizadas
HTML5 / CSS3: Estrutura semântica e design responsivo (Mobile First).
JavaScript (Vanilla): Lógica de aplicação, manipulação de DOM e integração de voz.
Google Tag Manager (GTM) / DataLayer: Estrutura de monitoramento seguindo padrões de mercado (GA4).
